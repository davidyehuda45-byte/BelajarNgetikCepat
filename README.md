# ⌨️ Belajar Ngetik Cepat (Typing Speed Test)

Aplikasi tes kecepatan mengetik (*Typing Speed Test*) interaktif yang dibangun menggunakan **Vanilla JavaScript murni**. Proyek ini dirancang dengan tampilan antarmuka yang modern, responsif, serta dilengkapi dengan fitur analisis statistik *real-time*.

[https://davidyehuda45-byte.github.io/BelajarNgetikCepat/](https://davidyehuda45-byte.github.io/BelajarNgetikCepat/)

---

## ✨ Fitur Utama

- **Real-Time WPM & Accuracy:** Menghitung kata per menit (Words Per Minute) dan tingkat akurasi secara akurat saat mengetik.
- **Dynamic Typing Visual Feedback:** Umpan balik visual langsung (merah untuk kesalahan, warna aksen untuk ketikan benar).
- **Infinity Mode (Stopwatch):** Fitur mode tanpa batas waktu yang bisa dihentikan kapan saja menggunakan tombol `Enter` atau `Escape`.
- **Statistik Interaktif (Chart.js):** Grafik performa kecepatan ngetik yang diperbarui secara langsung.
- **Auto-Focus & Smooth Input Capture:** Pengalaman mengetik yang mulus tanpa perlu mengeklik area teks terlebih dahulu.
- **Dark Theme Interface:** Desain antarmuka gelap yang nyaman di mata dengan aksen warna modern.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5:** Struktur dasar halaman web.
- **CSS3:** Styling kustom dengan tema Gelap (Dark Mode).
- **JavaScript (ES6+):** Logika manipulasi DOM, kalkulasi skor, dan event listener.
- **Chart.js:** Library untuk visualisasi grafik data performa ngetik.
